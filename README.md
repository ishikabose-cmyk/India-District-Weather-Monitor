# India District Weather Monitor

## Project Description
India District Weather Monitor is a weather analysis project that provides district-wise and state-wise weather information across India.

The project has two implementations:
1. Python-based weather analysis.
2. Interactive HTML-based weather dashboard.

## Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- SciPy
- HTML
- CSS
- JavaScript
- Chart.js

## Project Files
- `india_weather_monitor_pandas.py` – Python weather analysis program.
- `weather-1.csv` – Weather dataset used by the Python program.
- `India District Weather Monitor.html` – Interactive web dashboard.

## Features
- District-wise weather analysis.
- Temperature risk classification.
- Heat index and wind chill calculations.
- Weather statistics and charts.
- State-wise temperature map.
- District search and comparison.
- Data quality checking.
- Interactive dashboard.

## How to Run

### Python Program
Install the required libraries:
`pip install numpy pandas matplotlib seaborn scipy`

Run:
`python india_weather_monitor_pandas.py`
Keep `weather-1.csv` in the same folder.

### HTML Dashboard
Open `India District Weather Monitor.html` in a web browser with an internet connection.

## Dataset
The HTML dashboard contains an embedded dataset covering 20–23 January 2025. The Python program uses the separate CSV dataset.

## Project Purpose
To analyze and visualize weather conditions across Indian districts and provide an interactive way to explore weather information.
